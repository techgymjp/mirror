# 犬も歩けば鏡に当たる

壁がぜんぶ鏡になっている迷路から、犬になって脱出するカジュアル Web ゲーム。
錯覚と方向感覚が勝負です。

## 遊び方

- あなたは犬（一人称視点）。迷路の中を **自動で前へ走りつづけます**。
- **フリック ← →** で次のマスで曲がる / **↓** で U ターン / **タップ** でおすわり（止まる・走る）
- PC: `←` `→` `↓` / `Space` おすわり / `K` くんくん / `M` 地図 / `Esc` 一時停止
- 壁はすべて鏡。道が続いて見えても映りこみかもしれません。曲がり損ねると「ゴン！」
- 鏡には自分の姿も映ります。
- **本物の出口は一つだけ**。ほかの「EXIT」はワープゾーンで、迷路のどこかへ飛ばされます。
- 👃 くんくん（1ステージ3回）で本物の出口の方向がわかります。
- ゴン＋ワープの回数が少ないほど ★ が増えます。全5ステージ＋クリア後の「きまぐれ迷宮」。

## 起動

ビルド不要。`index.html` をブラウザで開くだけで遊べます（ローカルファイルでも動きます）。

```bash
python3 -m http.server 8000
```

## 構成

| ファイル | 内容 |
| --- | --- |
| `js/maze.js` | シード付き迷路生成（出口・ワープ扉・ほねの配置） |
| `js/renderer.js` | 鏡を反射するレイキャスター。反射を「折り返した空間を直進する」変換で扱い、鏡の奥の自分・扉・ほねも描画 |
| `js/sprites.js` | 犬（正面/背面/横・歩きアニメ）、ほね、扉テクスチャをキャンバスで生成 |
| `js/audio.js` | WebAudio の効果音（ゴン、ワン、ワープなど） |
| `js/game.js` | 自動走行・フリック入力・ステージ進行・HUD・セーブ（localStorage） |

ステージ設定は `js/game.js` の `STAGES` で調整できます（迷路サイズ、ループ数、ワープ数、鏡の色味の強さ `tint`、走る速さ `speed`、コンパス有無、ワープ扉の見分けやすさ `warpHint`）。
